# openapi-test-framework

Фреймворк для **автоматической генерации тестов REST API** на основе OpenAPI-спецификации.

Курсовая работа. Инструмент анализирует OpenAPI/Swagger-спецификацию и автоматически
порождает набор тестов трех видов, а также выявляет расхождения между документацией
и фактическим поведением API:

- **smoke** - happy-path вызов каждого эндпоинта;
- **контрактные** - соответствие статусов, заголовков и схем ответов спецификации;
- **fuzz (property-based)** - генерация входных данных из JSON-схем (Kotest property).

## Стек

Kotlin · JUnit 5 (`@TestFactory`) · REST Assured · Kotest (property) · swagger-parser ·
KotlinPoet (кодогенерация `.kt`) · WireMock (демо) · Allure (отчёты) · GitHub Actions (CI).

## Структура

| Модуль  | Назначение                                                        |
|---------|------------------------------------------------------------------|
| `core`  | сам фреймворк: парсинг спеки, генерация данных и тестов, валидация |
| `demo`  | эталонная спека Petstore, WireMock-мок, e2e-прогон, Allure        |

## Сборка и запуск

```bash
./gradlew build           # компиляция + юнит-тесты core
./gradlew :demo:test      # e2e против WireMock-мока
./gradlew allureReport    # отчёт Allure
```
